# Trilha de certificações

Cursos interativos de estudo para certificações de segurança e identidade: lição em partes curtas e animadas, seguida de uma prova com perguntas sorteadas de um banco (várias redações por conceito, alternativas embaralhadas, erros voltando com mais frequência).

Site estático, sem dependências. Para rodar localmente, abra `index.html` no navegador.

O conteúdo é escrito a partir dos guias oficiais públicos dos exames. Não contém perguntas reais de prova nem material oficial. Não é afiliado à ISC2 nem a outras certificadoras.
